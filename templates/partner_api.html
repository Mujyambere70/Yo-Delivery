🤝 Courier partner API

Courier companies that deliver Yo parcels where we have no couriers send their tracking events to us. Ask Yo Delivery for a key: you get a key id and a secret (shown once).

Signing a request

The technical part of this page is in English (the language of the API).

  1. Take the time now as a Unix number, for example 1762500000.
  2. Make the HMAC-SHA256 of <time>.<body> with your secret (hex).
  3. Send the headers X-Yo-Key: pk_... and X-Yo-Signature: t=<time>,v1=<hmac>. Signatures older than 5 minutes are refused.

Events

POST /api/partner/v1/events with {"events": [{"event_id": "e-1", "number": "YO12345678", "type": "picked_up", "at": "2026-11-07T10:15:00Z", "place": "Nairobi"}]}. Every event_id is used once, so you can send it again safely.
